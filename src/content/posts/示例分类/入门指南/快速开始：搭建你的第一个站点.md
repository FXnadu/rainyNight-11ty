这是一篇示例文章，用于展示主题的基本效果。你可以直接把它替换成自己的内容，或者删除整个 `示例分类` 文件夹从零开始。

## 环境准备

只需要安装 [Node.js](https://nodejs.org/) 18 或更高版本。

## 三步启动

```bash
npm install   # 安装依赖
npm start     # 启动本地开发服务器
npm run build # 构建静态文件到 _site/
```

## 内容组织

在 `src/content/posts/` 下按「分类/子分类」建立文件夹并放入 Markdown 文件，分类体系会自动生成，无需手动注册：

```
src/content/posts/
└── 示例分类/
    ├── 入门指南/
    │   └── 快速开始：搭建你的第一个站点.md
    └── 进阶技巧/
        └── 自定义样式与部署.md
```
