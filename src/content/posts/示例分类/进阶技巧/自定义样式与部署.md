## 样式结构

主题样式按模块拆分在 `src/assets/css/` 下：

- `foundation.css` — 设计变量（颜色、间距、字体）与基础样式
- `layout.css` / `components.css` — 布局与通用组件
- `pages/` — 各独立页面的专属样式

改配色只需调整 `foundation.css` 中的 CSS 变量，全站会跟着变化，构建时自动合并，无需手动处理引入关系。

## 自定义脚本

全站行为脚本在 `src/assets/js/main.js`，包含搜索、主题切换、移动端菜单等模块，按页面按需初始化。

## 部署

`npm run build` 会在 `_site/` 生成纯静态文件，任意静态托管平台都可以直接使用：

| 平台 | 构建命令 | 产物目录 |
| --- | --- | --- |
| GitHub Pages | `npm run build` | `_site/` |
| Netlify | `npm run build` | `_site/` |
| Vercel | `npm run build` | `_site/` |

> [!TIP]
> URL 结构说明：文章标题是中文时，会自动编码为 `p` 开头的短 ID（如 `/posts/p1a2b3c/`），并且旧标题链接会自动生成重定向页，改名文章也不会 404。
